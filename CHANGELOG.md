# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.16] - 2026-10-07

### Changed
- Storefront colours follow the store palette on Hyva and Luma: image and thumbnail backgrounds #FAFAFA (were #F9FAFB and #F3F4F6), borders #E5E5E5 (were #E5E7EB), thumbnail borders #D4D4D4 with #525252 on hover (were #9CA3AF and #4B5563).
- The default gallery CSS variables use the same values: border and thumbnail border #E5E5E5, muted text #525252.
